# Support

Novaroma is published under the Marketplace publisher ID `JestingDart4369` and maintained in free time, as a personal open-source project.

## Questions, bugs and ideas

Open an issue on GitHub: https://github.com/JestingDart4369/novaroma-vscode/issues

Please include:

- the Novaroma version (Extensions view → Novaroma) and your VS Code version (Help → About),
- the theme you use (for example Novaroma Herbst Dark Swapped),
- what you expected and what happened, with a screenshot if it is about colours or icons.

## Before opening an issue

- Run **Novaroma: Apply Theme Now** from the Command Palette. This sets the colour theme, the file icon theme and the product icon theme together.
- If a colour looks wrong, check whether another extension or your own `workbench.colorCustomizations` setting overrides it.
- If a profile changed something you did not want, run **Novaroma: Undo Last Profile**.

## Security

Novaroma makes no network requests and does not read your files (see PRIVACY.md). If you still find something that looks like a security problem, open an issue without details and ask for a private contact.
